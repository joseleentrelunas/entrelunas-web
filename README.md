# Entrelunas · web

Página estática: `index.html` + carpeta `assets/`. No necesita instalar nada ni compilar.

## Subir a GitHub
1. Crea un repositorio nuevo en github.com (por ejemplo `entrelunas-web`).
2. Pulsa "uploading an existing file" y arrastra TODO el contenido de esta carpeta (index.html, assets, README.md, vercel.json).
3. Commit changes.

## Publicar en Vercel
1. En vercel.com, "Add New… > Project" e importa el repositorio.
2. Framework Preset: **Other**. Build Command y Output Directory: vacíos.
3. Deploy. Cada cambio que subas a GitHub se publica solo.
